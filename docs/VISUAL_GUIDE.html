Feature contract

If a change breaks one of these, it is a regression, not a refactor.

Selection awareness

With one or more nodes selected, layouts, align, and snap act on the selection only.

Append-only notes

Markdown sync adds missing wikilinks at the footer and never rewrites prose.

Opt-in auto-sync

Background reconciliation defaults to off; per-canvas rules override globally.

Budgeted expansion

Expansion stops at 2 hops, 100 nodes, 250 edges and never covers existing cards.

Responsive picker

Search debounces 120 ms, Escape clears, and close cancels the timer.

Waveform limits

Decode caps at 15 minutes, cached by path + mtime, context always closed.

Graph honesty

Health score is advisory; cleanup removes only true duplicate edge pairs.

Scoped styling

Every class is ctk-*; the glass body class leaves on unload.

Decisions worth knowing

Each one replaced a specific failure.

Chosen

Plans, never direct writes

Preview, verification, undo, and rollback all come from one path.

Chosen

Whole-canvas snapshots

Restoration is exact even after several transforms in one operation.

Chosen

Canonical JSON compare

Key order and formatting never abort a valid transaction.

Chosen

Metadata cache as truth

Aliases, embeds, and unresolved targets behave exactly like Obsidian.

Chosen

Lossless adapter

Unknown JSON Canvas fields round-trip through every write.

Chosen

Normalize on load

No version field; one idempotent validator for stored and imported data.

Landmines

The failures that look like small cleanups until they corrupt a canvas.

Trap

Forcing stale writes

If the file changed since preview, abort. Overwriting discards user edits.

Trap

Re-entrant commits

Canvas events trigger auto-sync; the active lock is what stops nesting.

Trap

Dropping extra fields

Rebuilding nodes from known keys deletes plugin-specific canvas data.

Trap

setData without save

The change looks applied and disappears when the vault reloads.

Trap

Duplicate wikilinks

Check both [[Note]] and [[Note|alias]] before appending.

Trap

Broad unlink regex

Only standalone wikilink lines may be removed; inline text stays.

Trap

Loose media roots

Substring matching pulls in sibling folders with the same name.

Trap

Leaked audio context

Close the context and clear the progress interval or memory climbs.
